Make each section fill the screen — not float in it

The mobile build works. What makes it feel cluttered is the mix: content locked to one screen but only half-filling it, the same scaffolding repeated, and four different ways to scroll. Two directions per section below — a conservative fix that keeps each section's identity, and a bolder version on one shared system.

What reads as clutter

Content in a voidEvery section is min-height: 100svh but fills ~40–60%. A wide empty band sits under each one.
Repeated scaffolding#my-taste alone: three labels, two swipe rows, two dot indicators — for ten items.
Four scroll idiomsFilmstrip (experience), swipe rows (my taste), accordion (projects), static stack (about). Nothing rhymes.
Edge-bleedHorizontal rows slice cards on both screen edges at once, so nothing has a clean start or end.

The shared system — “unified” column

Let sections breathe to their contentDrop one-section-one-screen on phones. Natural height, bounded padding (64 top / 48 bottom).
One section headerMono kicker + one line of context. Same treatment in all six.
One horizontal idiom, used onceA peek-carousel: active card + next card peeking + dots. Only where the content is genuinely visual.
One card12px radius, image top / text bottom, 16px padding, one surface colour.
One edge rhythm20px gutter. Rows snap-align to it; the last card rests with a trailing gutter. No symmetric half-cards.
